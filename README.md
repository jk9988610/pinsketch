# PinSketch

PinSketch 是一个轻量级、离线可用的引脚—网络关系图工具，适合嵌入式开发中的芯片、传感器、连接器与外围器件连通记录。

双击 `index.html`（或 `PinSketch.bat`）即可启动，无需安装或联网。

## 项目结构

```
PinSketch/
├── index.html          # HTML 入口
├── css/
│   └── style.css       # 全局样式
├── js/
│   ├── core.js         # 状态管理、几何运算、网络图（并查集）、Undo/Redo
│   ├── components.js   # 元件类型定义、放置/删除/复制/粘贴、芯片库、蓝图捕获/放置
│   ├── storage.js      # IndexedDB 统一存储（文件库/蓝图库/芯片库）+ localStorage 兜底
│   ├── render.js       # SVG 渲染（含背景矩形、蓝图模式光标）
│   ├── analysis.js     # ERC 电气规则检查、网表导出
│   ├── blueprints.js   # 蓝图库逻辑（框选捕获/卡片化管理/放置/重命名/删除）
│   ├── ui.js           # 属性面板、模态框、右键菜单、文件库 UI、帮助
│   └── app.js          # 主入口、事件绑定、快捷键、初始化
├── PinSketch.bat       # Windows 启动脚本
└── README.md
```

## 0.3 新功能

### 蓝图库（类异星工厂蓝图系统）

- **框选蓝图（B）**：点击顶部"📐 框选蓝图"按钮或在蓝图库中点击"框选蓝图"，鼠标变为十字光标。拖动鼠标框选区域，松开后输入名称保存为蓝图。
- **放置蓝图**：在蓝图库中点击卡片或"放置"按钮，然后在画布上点击放置位置。蓝图中的元件和内部导线会被整体复制，ID 自动重新分配。
- **卡片化管理**：蓝图以卡片形式展示，可重命名和删除。蓝图保存在浏览器 IndexedDB 中，按更新时间排序。

### 文件库与保存

- **另存为**：将当前工程以指定名称保存到文件库（IndexedDB），可随时重新打开。
- **文件库**：在文件库中管理所有已保存文件，支持打开、重命名和删除。
- **保存（Ctrl+S）**：下载 `.pins.json` 文件到本地磁盘，作为归档备份。
- **打开**：从本地磁盘打开 `.pins.json` 文件，或从文件库打开已保存文件。
- **状态栏显示当前文件名**：底部状态栏始终显示当前正在编辑的文件名。

### 远程连接点（隐藏网络）

- 按 `M` 放置紫色远程连接点，在右侧填写网络名，例如 `KEY_L`、`USB_P`；
- 用短导线把远程点接到芯片或按键引脚；
- 另一处再放一个同名远程点并接线，两端即隐藏连通，画布上不画跨区域长线；
- 选中远程点或对应引脚会高亮整网；网表会以该名称作为网络名；
- ERC 会提示孤立远程点、未接线远程点，以及同一网络上的名称冲突。

### IndexedDB 统一存储

- 三个独立的 object store：`files`（文件库）、`blueprints`（蓝图库）、`chips`（芯片库）
- localStorage 兜底：自动恢复、UI 记忆、芯片库/蓝图库缓存

## 0.2 功能保留

### 连通可靠性

- 自定义芯片和连接器引脚，以及常用基础器件；
- 引脚、网络标签和显式连接点组成实际网络；
- 同名网络标签自动合并；
- 正交导线仅可连接引脚或连接点；线条交叉默认**不连通**；
- 选中对象时高亮整网；
- ERC：悬空引脚、重复位号、标签冲突、两端短接；
- JSON 保存/打开、网表文本导出、自动保存与撤销/重做。

### 效率编辑

- 拖曳画布空白处进行框选；`Shift + 点击` 增减多选；
- 批量移动、批量删除；
- `Ctrl/Cmd + C` 与 `Ctrl/Cmd + V` 复制、粘贴元件和内部导线（粘贴跟随鼠标位置）；
- 多选后可批量拖动、复制、删除；
- `Ctrl + 滚轮` 缩放画布；中键拖动或 `Shift + 左键拖动` 平移；
- 双击标题栏进入/退出浏览器全屏；
- 双击已存在导线添加拐点；选中导线后拖动黄色方块调整拐点；
- 自定义芯片/连接器可从右侧属性面板保存到芯片库，并在顶部"芯片库"中重复放置或删除；
- 画布及元件右键菜单支持复制、粘贴、删除、布线、框选蓝图、芯片库、蓝图库、文件库、另存为与 ERC 等快捷操作。

## 基本操作

1. 选择左侧元件并放置，右侧编辑位号、型号、数值和芯片引脚；
2. 按 `W` 选择导线，依次点击两个蓝色引脚、青色连接点或紫色远程点；
3. 多条导线要并接时，先按 `J` 放置连接点，再将导线连接到该点；
4. 跨区域信号按 `M` 放置远程连接点，两端填写相同名称（如 `KEY_L`），再用短线接到对应引脚；
5. 也可按 `L` 放置网络标签；填写相同名称即可跨画布形成同一网络；
6. 按 `B` 进入蓝图框选模式，拖动鼠标框选区域，松开后保存为蓝图；
7. 在蓝图库中选择蓝图，点击画布放置蓝图；
8. 点击"ERC 检查"定位基础连通错误；
9. `Ctrl + Z` / `Ctrl + Y` 撤销/重做，`Ctrl + S` 下载工程文件；
10. 点击"另存为"将工程保存到文件库，或点击"文件库"管理已保存文件。

## 注意

PinSketch 不是完整 PCB EDA，重点是可靠、高效地维护引脚—网络关系。浏览器会保存本机恢复副本，重要工程仍应下载 `.pins.json` 归档。文件库、蓝图库和芯片库使用 IndexedDB 存储，清除浏览器数据会一并删除。
