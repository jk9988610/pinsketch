# PinSketch

PinSketch 是一个轻量级、离线可用的引脚—网络关系图工具，适合嵌入式开发中的芯片、传感器、连接器与外围器件连通记录。

双击 `index.html`（或 `PinSketch.bat`）即可启动，无需安装或联网。

## 项目结构

```
PinSketch/
├── index.html          # HTML 入口
├── css/
│   └── style.css       # 全局样式
├── js/
│   ├── core.js         # 状态管理、几何运算、网络图（并查集）、Undo/Redo
│   ├── components.js   # 元件类型定义、放置/删除/复制/粘贴、芯片库
│   ├── storage.js      # 自动保存、文件下载/打开
│   ├── render.js       # SVG 渲染
│   ├── analysis.js     # ERC 电气规则检查、网表导出
│   ├── projects.js     # 设计目录（IndexedDB 持久化）
│   ├── ui.js           # 属性面板、模态框、右键菜单、帮助
│   └── app.js          # 主入口、事件绑定、快捷键、初始化
├── PinSketch.bat       # Windows 启动脚本
└── README.md
```

## 0.3 新功能

### 设计目录

- **保存到目录**：点击顶部"设计目录"按钮，输入名称后将当前设计保存到浏览器本地数据库（IndexedDB），无需下载文件即可持久保存；
- **打开设计**：在设计目录对话框中点击卡片或"打开"按钮即可加载历史设计；
- **管理**：支持重命名和删除；设计按更新时间排序；
- 设计目录与 `.pins.json` 下载文件独立存储，可互为备份。

### 代码重构

- 将单一 `app.js` 拆分为 8 个模块，按职责分离；
- 修复了原版 `showProps` 函数重复定义的 bug；
- 修复了 `remote` 工具在画布上无法放置的问题；
- 新增 `Esc` 键取消导线绘制；
- 网表导出头部升级至 `PinSketch 0.3`。

## 0.2 功能保留

### 连通可靠性

- 自定义芯片和连接器引脚，以及常用基础器件；
- 引脚、网络标签和显式连接点组成实际网络；
- 同名网络标签自动合并；
- 正交导线仅可连接引脚或连接点；线条交叉默认**不连通**；
- 选中对象时高亮整网；
- ERC：悬空引脚、重复位号、标签冲突、两端短接；
- JSON 保存/打开、网表文本导出、自动保存与撤销/重做。

### 效率编辑

- 拖曳画布空白处进行框选；`Shift + 点击` 增减多选；
- 批量移动、批量删除；
- `Ctrl/Cmd + C` 与 `Ctrl/Cmd + V` 复制、粘贴元件；
- 多选后可左对齐，或在右侧属性面板执行横向等距；
- `Ctrl + 滚轮` 缩放画布；中键拖动或 `Shift + 左键拖动` 平移；
- 双击标题栏进入/退出浏览器全屏；
- 双击已存在导线添加拐点；选中导线后拖动黄色方块调整拐点；
- 自定义芯片/连接器可从右侧属性面板保存到本机芯片库，并在顶部"芯片库"中重复放置或删除；
- 自动记忆芯片库、上次画布、缩放、滚动位置和当前工具；
- 画布及元件右键菜单支持复制、粘贴、删除、布线、对齐、连接点、芯片库、设计目录与 ERC 等快捷操作。

## 基本操作

1. 选择左侧元件并放置，右侧编辑位号、型号、数值和芯片引脚；
2. 按 `W` 选择导线，依次点击两个蓝色引脚或青色连接点；
3. 多条导线要并接时，先按 `J` 放置连接点，再将导线连接到该点；
4. 按 `L` 放置网络标签；填写相同名称即可跨画布形成同一网络；
5. 点击"ERC 检查"定位基础连通错误；
6. `Ctrl + Z` / `Ctrl + Y` 撤销/重做，`Ctrl + S` 下载工程文件；
7. 点击"设计目录"保存设计到浏览器本地数据库，随时重新打开。

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `V` | 选择 / 移动 |
| `W` | 正交导线 |
| `L` | 网络标签 |
| `J` | 连接点 |
| `R` | 远程连接点 |
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Y` | 重做 |
| `Ctrl/Cmd + S` | 保存 .pins.json |
| `Ctrl/Cmd + C` | 复制 |
| `Ctrl/Cmd + V` | 粘贴 |
| `Delete` | 删除选中 |
| `Esc` | 取消导线绘制 |
| `Ctrl + 滚轮` | 缩放画布 |

## 注意

PinSketch 不是完整 PCB EDA，重点是可靠、高效地维护引脚—网络关系。浏览器会保存本机恢复副本，重要工程仍应下载 `.pins.json` 归档。设计目录使用 IndexedDB 存储，清除浏览器数据会一并删除。
